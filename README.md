# HideNotch

A small macOS app that hides the notch. What did you think the name meant?

<img src="./screenshot.png" alt="Screenshot of the app" width="450">

## How to run

First, ensure you have [Homebrew](https://brew.sh/) and the [Xcode command-line tools](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools) installed. Then, install CMake from Homebrew with the following command:

```sh
brew install cmake
```

Finally, run `make` to build the project, and open it using `open ./build/HideNotch.app`, or through Finder.
