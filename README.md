# HideNotch

A small macOS app that hides the notch. What did you think the name meant?

<img src="./screenshot.png" alt="Screenshot of the app" width="450">

## How to run

1. Ensure you have the [Xcode command-line tools](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools) installed, as well as [CMake](https://cmake.org/) (from [Homebrew](https://brew.sh/) or otherwise).
2. Run `make` to build the project, and open it using `open ./build/HideNotch.app`, or through Finder.
